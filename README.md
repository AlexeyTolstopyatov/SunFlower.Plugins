# SunFlower plugins

<img src="assets/sunflower256.png" height=128 align="right"> 

This repository contains plugins which always include
in [SunFlower](https://github.com/AlexeyTolstopyatov/SunFlower) releases

> [!NOTE] At the moment of SunFlower 5.0 release
> Plugins are in active testing and developing stage and some of
> functions are not work correct or might be not implemented at all
>
> See readme files of plugin

There are some plugins source code presented: 
 - [MZ](/plugins/Sunflower.Mz/README.md) DOS relocatables
 - [NE](/plugins/SunFlower.Ne/README.md) Win16 and OS/2 1.x applications
![Win16 IDA versus](/assets/idaversus_win16.png)
 - [LE](/plugins/SunFlower.Le/README.md) Microsoft OS/2 2.0 mixed code and Windows VxD drivers
 - [LX](/plugins/SunFlower.Le/README.md) IBM OS/2 16/32-bit applications and drivers
![OS/2 IDA versus](/assets/idaversus_os2.png)
 - [PE](/plugins/SunFlower.Pe/README.md) Windows NT/UEFI 32 and 64 bit applications 
 - AOUT old Unix applications (applied in Plan9/Iris/...)
 - ELF applications 
 - Mach-0 macOS/iOS/... applications
